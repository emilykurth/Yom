# Yom

A little phone app for rating the same food (strawberry smoothies, cinnamon rolls, cheeseburgers…) across every place you try it.

- Make a category, pick an icon, and choose the qualities you rate it on
- Rate each quality 0–10 with a slider; untick a box for things like price so they don't count toward the overall score
- See the overall average (and stars), per-quality averages, and sort by recent, favorites, lowest or location
- Add a restaurant, location, menu item, date, notes and a photo to every rating
- Build your own avatar and pick a colour theme
- Works offline; data stays on your phone (Profile → Save backup now and then)

**Install on iPhone:** open the GitHub Pages link in Safari → Share → Add to Home Screen.

The first version of the design is kept at `/original/`.
