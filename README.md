# Tastebook

A little phone app for rating the same food (strawberry smoothies, cinnamon rolls, pizza slices…) across every place you try it.

- Make a category, pick an icon, and choose the qualities you rate it on
- Rate each quality 0–10 with a slider; untick "Count toward overall" for things like price
- See the overall average, per-quality averages, and sort by recent, highest, lowest or location
- Add a photo to every rating
- Works offline; data stays on your phone (use Profile → Save backup now and then)

**Install on iPhone:** open the GitHub Pages link in Safari → Share → Add to Home Screen.
